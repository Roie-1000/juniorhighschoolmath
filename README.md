# 會考數學總複習

給國中教育會考考生的數學複習網站，依 108 課綱排成 28 個單元（七上到九下）。

- **每個單元**：重點複習、易錯觀念、會考難題拆解、練習 10 題（可選依序或隨機出題）
- **較難的 11 個單元**：另附白話講解與口訣
- **模擬考**：每回 25 題，15 題模擬考專用題（題庫 662 題）混合 10 題基本題，可複選年級範圍；交卷後顯示分數、各單元答對率與錯題解析；會記住考過的題目，盡量不重複
- **公式**：28 個單元的重要公式總整理
- **錯題本**：練習與模擬考答錯的題目自動收錄，可按單元重做，連續答對 2 次自動移出
- **學習進度**：各單元答對率、模擬考分數變化、最該先複習的單元
- **考前衝刺**：設定會考日期後倒數，依剩餘天數與答對率自動排每日單元與模擬考，進度表排到考前兩週
- **幾何附圖**：相似形、圓、三心、四邊形等題目附上示意圖（src/figs.js）

學習紀錄存在使用者自己的瀏覽器（localStorage），換裝置或清除瀏覽資料會重新計算。

整個網站是一個獨立的 `index.html`，不需要伺服器或安裝任何東西，用瀏覽器打開就能用。

## 修改內容

題目與講義放在 `src/`：

| 檔案 | 內容 |
| --- | --- |
| `src/data1.js` | 七上、七下單元 |
| `src/data2.js` | 八上、八下單元 |
| `src/data3.js` | 九上、九下單元 |
| `src/extra.js`、`src/extra2.js`、`src/bank*.js` | 模擬考專用題 |
| `src/formulas.js` | 各單元重要公式 |
| `src/template.html` | 版面、樣式與程式 |

改完後執行 `python3 src/build.py`，重新產生根目錄的 `index.html`。

## 架站

在 repo 的 Settings → Pages，Source 選 “Deploy from a branch”，分支選 `main`、資料夾選 `/ (root)`，儲存後幾分鐘網站就會上線。
